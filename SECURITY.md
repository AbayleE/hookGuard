# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through [GitHub security advisories](https://github.com/AbayleE/hookGuard/security/advisories/new). Include the affected version, the provider involved, and steps to reproduce.

Examples of what to report:

- Accepting a forged or altered webhook
- Bypassing a replay window
- Exposing a secret

A report that a genuine webhook fails to verify is usually a normal bug, so please use the [issue tracker](https://github.com/AbayleE/hookGuard/issues) for that.

## Supported versions

Security fixes go to the latest published release.
